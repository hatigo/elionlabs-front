# ElionLabs - Site Institucional

Projeto estático pronto para deploy no GitHub Pages.

Como usar:

1. Atualize `index.html` meta `og:url` com a URL do GitHub Pages (já definida para https://hatigo.github.io/elionlabs-front/).
2. Faça commit e publique no GitHub.
3. Ative GitHub Pages nas configurações do repositório (branch `main` / `gh-pages`).
